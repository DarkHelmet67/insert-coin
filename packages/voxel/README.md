# @arcade/voxel

Dal disegno 2D ai voxel: un contesto di disegno che registra i rettangoli invece di dipingerli, così il codice di disegno di un gioco a pixel gira identico e il risultato si può estrudere in 3D; più le funzioni che trasformano rettangoli e sprite in voxel, un cubo per pixel. Non dipende da Three.js.

Stato: disponibile. Guida: [20 · Remaster 2.5D](../../docs/20-remaster-2-5d.md).
