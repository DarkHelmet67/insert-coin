# @arcade/debug

La modalità debug comune a tutti i giochi: l'interruttore letto da `tuning.config.ts`, l'accensione forzata nelle anteprime delle pull request, la scritta DEBUG sullo schermo e il record che non viene salvato.

Stato: disponibile. Guida: [18 · Modalità debug](../../docs/18-modalita-debug.md).
