# @arcade/particles

Esplosioni di particelle pure e testabili: ogni frammento di un oggetto vola via dal centro, ruota, cade e si rimpicciolisce fino a sparire. Il caso arriva da una funzione passata come parametro, così i test sono ripetibili. Non dipende da Three.js.

Stato: disponibile. Guida: [20 · Remaster 2.5D](../../docs/20-remaster-2-5d.md).
