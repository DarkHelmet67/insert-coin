# Lunar Lander

Remake di _Lunar Lander_ (Atari, 1979) su HTML5 Canvas, costruito sui pacchetti condivisi `@arcade/*`.

Stato: **in costruzione**. Per ora c'è la pagina vuota e la ricerca sul gioco originale, fatta sul suo codice sorgente.

```bash
pnpm dev:lunar-lander  # dalla root del monorepo
pnpm build             # output in games/lunar-lander/dist: index.html + game.css + game.js
```

## Guide del gioco

- [Le meccaniche dell'originale](docs/meccaniche-originali.md): schermo, terreno e zoom, modulo, missioni, carburante, atterraggio e suoni, ricavati dal sorgente originale di Atari.
